# ShadowFox Java Developer Internship

This repository contains my project submissions for the **ShadowFox Java Developer Internship** across progressive difficulty levels:

1. **Beginner Level (`Task1-Student-Helpdesk-System`):** Modular Java console-based student helpdesk & support ticket management system built using OOP principles.
2. **Intermediate Level (`Task2-Employee-Leave-Management`):** RESTful backend API built with Java, Spring Boot, JPA/Hibernate, and MySQL/PostgreSQL following layered architecture.
3. **Advanced Level (`Task3-Smart-Classroom-Booking`):** Real-time Android-based Smart Classroom Seat Booking application built using Java in Android Studio.
